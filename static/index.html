Research methodology

PromptForge generates six candidate strategies and evaluates model outputs using transparent heuristics. The mock provider enables offline exploration without an API key; local inference runs with Ollama (e.g. gemma3:1b or llama3.2); and cloud route connects to any OpenAI-compatible provider.

Relevance proxy measures keyword overlap with the original prompt. Length proxy measures response length. Structure proxy detects list or heading patterns. When supplied, reference keyword recall measures overlap with a reference answer. None of these scores independently establish factual correctness.

For an academic experiment, connect a real model, define a held-out task dataset, use unit tests or human grading, compare with unoptimized prompts, and report uncertainty and limitations.
